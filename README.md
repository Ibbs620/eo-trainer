# EO Trainer
A training tool for FMC (3x3x3 Fewest Moves Challenge). The goal of the trainer is for FMC competitiors to practice the Edge Orientation (EO) step of the Domino Reduction method by finding as many sub-5 move EO sequences as possible within a time limit.

## Features
- Customizable time limit
- Togglable inverse scramble and 2D/3D scramble preview
- Filterable report of missed EOs after an attempt
- Finds NISS and inverse EOs
- Allows random or custom scrambles
